# Загрузка номенклатуры в 1С

Обработка для загрузки номенклатуры в 1С из внешних файлов различных форматов.

## Возможности

- Загрузка номенклатуры из TXT
- Загрузка номенклатуры из CSV
- Загрузка номенклатуры из Excel
- Загрузка номенклатуры из XML
- Загрузка номенклатуры из JSON
- Создание новых элементов номенклатуры
- Обновление существующей номенклатуры
- Сопоставление данных по наименованию или артикулу

## Технологии

- 1С:Предприятие 8.3
- TXT
- CSV
- Excel
- XML
- JSON

## Установка

1. Открыть обработку в 1С.
2. Выбрать формат загружаемого файла.
3. Указать файл с номенклатурой.
4. Выполнить загрузку данных.
